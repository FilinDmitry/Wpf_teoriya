## Модуль аутентификации и регистрации пользователей

Модуль предоставляет функционал для входа в аккаунт, регистрации новых пользователей и управления пользователями в базе данных.

### 🔐 Метод аутентификации
Статический метод для проверки учетных данных и выполнения входа.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `login_` | `string` | Логин пользователя |
| `password` | `string` | Пароль пользователя |

**Возвращаемое значение:**
- `true` — вход выполнен успешно
- `false` — введены неверные данные

### Метод регистрации
Проверяет данные и добавляет нового пользователя в базу данных.

| Параметр | Тип | Описание |
|----------|-----|----------|
| `user` | `Users` | Объект с данными пользователя |

**Действия:**
1. Добавляет запись в таблицу `Users`
2. Сохраняет изменения через `Core.Context.SaveChanges()`
3. Обновляет локальный кэш `lst_users`

### Переменные

| Переменная | Тип | Назначение |
|------------|-----|------------|
| `is_reg` | `bool` | Флаг авторизации |
| `login` | `string` | Логин текущего пользователя |
| `id` | `int` | ID текущего пользователя |
| `name` | `string` | Имя текущего пользователя |
| `lst_users` | `List<Users>` | Кэш пользователей из БД |

### Требования

- Контекст базы данных `Core.Context`
- Модель данных из приложенного SQL файла
- `WPF` для `MessageBox`

### Примечания

- Метод `Check_user` автоматически устанавливает глобальные переменные при успешном входе
- При неверных данных выводится сообщение через `MessageBox`
- В названии поля `Passworg` возможно опечатка (предполагается `Password`)

### Статус методов

| Метод | Уровень доступа | Статус | Назначение |
|-------|-----------------|--------|------------|
| `Check_user` | `public static` | Публичный | Авторизация пользователя |
| `Update` | `private static` | Внутренний | Регистрация пользователя |
